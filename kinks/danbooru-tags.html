How tags work in a prompt

Danbooru is an image board where every drawing carries a list of short tags, written in lowercase with underscores. Many anime image models learned from pictures labelled this way, so a prompt written as a list of tags, separated by commas, often works better than a sentence. Some tools want the underscores, others want spaces. Try both on your model. Vivian’s field notesFirst-hand experience, not a study.

Put the tags that matter most first: who is in the picture, then the look, then the pose, then the framing and the background. Keep a second list of what you don’t want, the negative prompt, for things like a watermark or a signature. Vivian’s field notesFirst-hand experience, not a study. The method, with examples, is in Images online, and running a model yourself is in Images at home.
